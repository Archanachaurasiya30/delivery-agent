  <files>

  <action>
    1. Create `backend/app/schemas/team.py` - Pydantic schemas:
       - `class TeamMemberCreate(BaseModel)`:
         - name: str (min_length=1, max_length=100)
         - email: EmailStr
         - role: str = "developer" (choices: "developer", "tech_lead", "qa", "designer", "devops")
         - capacity_hours_per_sprint: int = 40 (ge=0, le=80)
         - is_available: bool = True
       - `class TeamMemberUpdate(BaseModel)`:
         - All fields optional (for partial updates)
         - name: Optional[str], email: Optional[EmailStr], role: Optional[str], etc.
       - `class TeamMemberResponse(BaseModel)`:
         - All fields from model including id, created_at, updated_at
         - model_config = ConfigDict(from_attributes=True)
       - `class TeamMemberListResponse(BaseModel)`:
         - members: List[TeamMemberResponse]
         - total: int

    2. Create `backend/app/services/team_service.py` - Business logic:
       - `class TeamService`:
         - Constructor takes AsyncSession
         - `async def list_members(self, skip=0, limit=50) -> Tuple[List[TeamMember], int]`
         - `async def get_member(self, member_id: UUID) -> TeamMember` (raise 404 if not found)
         - `async def create_member(self, data: TeamMemberCreate) -> TeamMember`:
           - Check email uniqueness, raise 409 if duplicate
           - Create TeamMember from schema, add to session, flush, return
         - `async def update_member(self, member_id: UUID, data: TeamMemberUpdate) -> TeamMember`:
           - Load member, apply only provided fields (exclude_unset=True), return
         - `async def delete_member(self, member_id: UUID) -> None`:
           - Load member (404 if not found), delete, flush
         - `async def toggle_availability(self, member_id: UUID) -> TeamMember`:
           - Load member, flip is_available boolean, return

    3. Create `backend/app/api/v1/team.py` - API endpoints:
       - `router = APIRouter(prefix="/team", tags=["team"])`
       - `GET /team/members` -> TeamMemberListResponse
         - Query params: skip (default 0), limit (default 50)
       - `POST /team/members` -> TeamMemberResponse (status_code=201)
         - Body: TeamMemberCreate
       - `GET /team/members/{member_id}` -> TeamMemberResponse
       - `PATCH /team/members/{member_id}` -> TeamMemberResponse
         - Body: TeamMemberUpdate
       - `DELETE /team/members/{member_id}` -> 204 No Content
       - `POST /team/members/{member_id}/toggle-availability` -> TeamMemberResponse
       - All endpoints use `db: AsyncSession = Depends(get_db)` and instantiate TeamService(db)
       - Proper HTTP error responses: 404 for not found, 409 for duplicate email, 422 for validation

    4. Create `backend/app/services/__init__.py` (empty).

    5. Register team router in `backend/app/api/v1/router.py`:
       - Import team router, include it in v1 router

    Important: Service layer handles all business logic. API layer only handles HTTP concerns (parsing, status codes, error responses). This separation makes services testable independently.
    Important: Use `model_dump(exclude_unset=True)` for partial updates so only provided fields are changed.
  </action>
